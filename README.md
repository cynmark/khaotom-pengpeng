# ข้าวต้มเพ่งเพ้ง

A responsive static Thai restaurant website. Serve the dist directory with any static web server. Home: index.html; searchable menu: menu.html; photograph licenses: credits.html. Shared CSS and JavaScript are styles.css and app.js.

Menu dishes and prices are sample content; replace the menu array in dist/app.js with the confirmed restaurant menu before public customer use. Business contact details were supplied by the owner. No booking, order, or payment service is connected. There is no LINE account or link.

Food photography attribution is included in credits.html. Images are hosted locally, compressed, and lazy-loaded below the fold. Thai typography uses Noto Sans Thai with system fallback.
